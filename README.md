# 八百万OS / Yaoyorozu Operating System

ビッグアイデアは、海に新しい都市を浮かべることでも、火星に国を移すことでもない。

**すでに列島にある八百万の関係性を、国家OSとして起動すること。**

これは宣言のスライドではない。ブラウザを箕体にしたオペレーティングシステムである。

## 公開

- リポジトリ: https://github.com/ozekimasaki/yaoyorozu-os
- GitHub Pages: https://ozekimasaki.github.io/yaoyorozu-os/

## 起動（ローカル）

```bash
python3 -m http.server 8765
```

または:

```bash
npm install
npm run dev
```

ブラウザで開く。Enter、または「起動する」。

- `/` 鳥居（アプリ・県・神・最近の札）
- `;` 走っている窓
- `'` 空間送り（47カーネル）。`[` `]` は隣県
- `k` 柏手（左手と右手の認証）
- `m` 間（ログアウトではない。柏手か「間を終える」で起こす）
- 余白で右クリック: 軒先（新しい札・祭暦・機械・無縁・間）
- メニューの当直行: 氏子課（核ログ）。時計: 祭暦。コピー: 言霊の控え
- 奉納: ↑↓ 履歴、Tab 補完、find / grep / df / cp / echo / restore
- 裏に回すと時計と割込を止める。長く隠すと間に入る
- デスクトップの札は掴んで置ける
- ログアウトは遷宮まで EPERM

## 機械

| 層 | 中身 |
| --- | --- |
| Kernel | Worker 時計、当直ハッシュ、GEP / 無縁、syscall |
| 縁fs | IndexedDB。親索引。宣言・憲法は `/etc`。無縁匣から戻せる |
| 神 | ps。アタッチ、祓い、立てる。殺すUIはない |
| 注連縄 | 既定 deny。子ども・死者は外せない |
| 縁 | ソケット。ping と migrate が地図を変える |
| dmesg | すべての操作の核ログ |
| 列島 | 実形地図。県は空間。東京は親ではない |
| 奉納 | 同じカーネルを触るシェル。履歴と補完。複数窓可 |
| 間 | 通知沈黙。IRQ間隔。機械の眠り |

リロードしてもファイルと立てた神は残る。別タブは同一機械の別シェル。

## 本番デプロイ

```bash
npx wrangler deploy
```

静的アセットだけの Workers。`wrangler.jsonc` の `assets.directory` がサイト本体。
